# نقطني

واجهة Next.js لدعوات الزفاف والخطوبة والسبوع والعقيقة وعيد الميلاد.

الضيف يفتح رابطاً عاماً، يضغط «افتح الدعوة»، ثم يرى الموعد والمكان ويمكنه تأكيد الحضور وكتابة رسالة وإرسال نقطة تجريبية. صاحب الدعوة يستخدم رابط إدارة خاصاً.

`Frontend.md` و `Backend.md` هما خطة المشروع كما كُتبت في المحادثة. الصور المرجعية لخطوات الفتح في `public/images`.

```bash
npm run dev
```

هذه النسخة واجهة فقط. الدعوات والردود والنقطة تُحفظ في المتصفح، والدفع محاكاة بلا خصم حقيقي.
